# Contributing Guidelines

Welcome to the Ksw-God repository! We appreciate your interest in contributing to this project. Below are guidelines for adding templates and improving the codebase.

## Adding Templates
1. **Fork the Repository:** Begin by forking the repository to your own GitHub account.
2. **Create a New Branch:** Create a branch off `main` for your changes. Use a descriptive name for the branch, e.g., `add-template-feature`.
3. **Add Your Template:** Place your template files in the appropriate directory (e.g., `/templates`). Be sure to follow any existing naming conventions.
4. **Documentation:** Update this `CONTRIBUTING.md` file with details about the new template, including usage instructions.
5. **Pull Request:** Submit a pull request detailing your changes and why they would benefit the project.

## Improving Code
1. **Read the Code of Conduct:** Ensure you follow our [Code of Conduct](link-to-code-of-conduct).
2. **Error Checking:** Before making changes, check for open issues to see if your changes address any existing concerns.
3. **Code Style:** Follow the established code style and conventions used in the project. Consistency is key!
4. **Testing:** Write tests for any new features or bug fixes you introduce. Ensure that all tests pass before submitting your pull request.
5. **Review Process:** Be open to feedback and willing to make adjustments based on reviewer comments.

Thank you for your contributions! Together, we can make Ksw-God even better!
